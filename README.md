# Plataforma_analisis_biomecanico
En este repositorio se incluyen los codigos de adquisición de los datos de IMUs, adquisición de datos de EMG para la tarjeta Teensy, el envío de datos mediante JSON de IMUs, el envío de datos mediante JSON de EMG para la tarjeta ESP32, el codigo fuente en python para el servidor FLASK y el codigo en python para la plataforma en Blender.
